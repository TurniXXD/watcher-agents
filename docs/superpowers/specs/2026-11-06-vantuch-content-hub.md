5.2 Free food classification
This is an important feature.
The Brno Events Bot should detect whether an event explicitly offers free food or refreshments.
Examples of positive evidence:
Free pizza
Free lunch
Complimentary food
Food provided at no charge
Občerstvení zdarma
Jídlo v ceně vstupu, where the event itself is free
Distinguish between:
Free admission
Free food
Paid food
Unknown food availability
These are independent properties.
Use:
freeFood: "yes" | "no" | "unknown";
foodDetails: string | null;
Rules:
yes only when credible source information explicitly confirms free food.
no only when credible source information explicitly confirms food is not provided for free.
unknown when the information is absent or ambiguous.
Never infer free food merely because an event is free.
Never infer free food from generic mentions of refreshments without sufficient context.
Store supporting source evidence internally.
Allow editors to override the classification.
The public API must support:
GET /api/public/v1/events?freeFood=true
When enabled, return only events where freeFood is yes.
Include the food information in event details.

7. Preserve human edits
   This is a critical requirement.
   Bots must never silently overwrite content edited by a human.
   Store separately:
   Latest raw bot-generated data
   Current editorial content
   Pending proposed updates
   When a bot discovers changes to an existing event:
   Match it using stable source identifiers.
   Compare incoming data with the previous bot snapshot.
   Preserve human-edited fields.
   Store proposed changes.
   Mark the record as having pending updates.
   Allow editors to review and apply selected changes.
   Repeated identical submissions must not create duplicate versions.
   For new records, initialize editorial fields from the bot output.
   For existing approved records, preserve publication status unless a verified cancellation or critical correction requires special handling.
   Implement an explicit safety policy for cancellations and date changes so materially incorrect published information is not left visible indefinitely.
