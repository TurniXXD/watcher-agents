## Watcher runtime

The production workflow builds one shared image tagged with the exact commit
SHA. Deployment is serialized and follows this order:

1. Establish least-privilege Tailscale/SSH transport.
2. Back up PostgreSQL.
3. Pull the immutable application image.
4. Run committed Prisma migrations.
5. Roll out independent Compose services.
6. Verify health checks and capture failure logs.
7. Roll back the application image when health verification fails.

Runtime secrets remain on the server in mode-`0600` files under
`deploy/runtime`. Ollama remains external to Compose.

## Self-hosted documentation

The immutable Watcher image contains a standalone Next.js server. Production
Compose starts it as the `docs` service with these addresses:

| Scope               | Address                    |
| ------------------- | -------------------------- |
| Container           | `http://docs:3000`         |
| VPS loopback        | `http://127.0.0.1:3001`    |
| Cloudflare hostname | `https://docs.vantuch.dev` |

`DOCS_BIND_ADDRESS` and `DOCS_HOST_PORT` can change the host publication. Keep
the address on loopback unless direct network access is explicitly required.
`NEXT_PUBLIC_DOCS_URL=https://docs.vantuch.dev` sets the canonical build-time
origin and contains no secret.

The service joins the external `lateralis` network. Configure the existing
token-managed `cloudflared` container in Cloudflare Zero Trust with a public
hostname mapping from `docs.vantuch.dev` to `http://docs:3000`. The repository
does not store the tunnel token or generate the public-hostname mapping.

<Callout type="warn" title="Access protection is mandatory">
  Enable Cloudflare Access for `docs.vantuch.dev` before exposing the hostname.
  The generated `noindex` metadata and deny-all `robots.txt` do not prevent an
  unauthorized visitor from reading the deployment.
</Callout>

The normal VPS release starts and health-checks the docs container alongside the
other Watcher services. Creating the Cloudflare Access application and hostname
mapping remains a manual infrastructure step.
