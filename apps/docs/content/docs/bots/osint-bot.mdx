## Overview

OSINT Bot investigates names, Czech company identifiers, domains, labelled
addresses, cadastral selectors, public profile URLs, and supported public
identifiers. Name matches remain candidates. Public-register birth dates and
residential addresses are discarded; LLM inference is labelled and never stored
as a sourced fact.

## Commands

| Command                         | What it does                                                    |
| ------------------------------- | --------------------------------------------------------------- |
| `/start`, `/help`               | Shows the complete evidence and safety guide.                   |
| `/about`, `/osint_about`        | Explains purpose, data model, sources, and limits.              |
| `/investigate QUERY`            | Creates an investigation and runs matching collectors.          |
| `/investigations`               | Lists the operator's investigations and IDs.                    |
| `/investigation [ID]`           | Selects an investigation and displays its report.               |
| `/report [ID]`                  | Shows facts, entities, source failures, and labelled inference. |
| `/status`                       | Shows active investigation and watch state.                     |
| `/evidence [ID]`                | Lists evidence or opens one evidence record with provenance.    |
| `/entity ID`                    | Shows an entity and evidence-backed observations.               |
| `/relations [ID]`               | Shows evidence-backed investigation/entity relations.           |
| `/timeline [ID]`                | Builds a timeline from dated public records.                    |
| `/expand SELECTOR_OR_ENTITY_ID` | Adds a selector/entity and runs matching collectors.            |
| `/search ICO_OR_DOMAIN`         | Shortcut for expanding the active investigation.                |
| `/sources`                      | Lists implemented collectors, inputs, and limitations.          |
| `/watch [ID]` / `/unwatch [ID]` | Enables or disables change monitoring.                          |
| `/pause [ID]` / `/resume [ID]`  | Pauses future work or resumes and recollects.                   |
| `/stop [ID]`                    | Stops future runs for the investigation.                        |

## Architecture and flow

<Mermaid
  label="OSINT investigation and watch workflow"
  chart={`flowchart LR
    A["Authorized investigation or due watch"] --> B["Validate target and scope"]
    B --> C["Run bounded public collectors in parallel"]
    C --> D["Normalize evidence with provenance"]
    D --> E["Conservative entity resolution"]
    E --> F["Persist entities, relations, and timeline"]
    F --> G["Optional clearly marked Ollama synthesis"]
    G --> H["Telegram evidence report"]
    F --> I["Persisted watch target"]

An investigation fans out over bounded collectors, normalizes evidence with
provenance, resolves candidate entities conservatively, stores relations and
timeline events, and renders a Telegram report. Watch polling revisits persisted
targets. Optional Ollama produces clearly marked synthesis after deterministic
collection.

## Configuration

| Variable                     | Required/default | Purpose                                                       |
| ---------------------------- | ---------------- | ------------------------------------------------------------- |
| `DATABASE_URL`               | Required         | PostgreSQL evidence, entity, relation, and watch state.       |
| `OSINT_TELEGRAM_TOKEN`       | Required         | Dedicated Telegram token.                                     |
| `TELEGRAM_ALLOWED_USER_IDS`  | Required         | Authorized private operators.                                 |
| `OSINT_MAX_COLLECTORS`       | `12`             | Maximum collector concurrency.                                |
| `OSINT_WATCH_POLL_MINUTES`   | `5`              | Due-watch polling interval.                                   |
| `OSINT_HEALTH_PORT`          | `4060`           | Private readiness port.                                       |
| `OLLAMA_URL`, `OLLAMA_MODEL` | Optional pair    | Labelled, validated synthesis after deterministic collection. |
| `LOG_LEVEL`                  | `info`           | Structured log level.                                         |

## Execution and scheduling

```bash
pnpm --filter @watcher/osint-bot dev
pnpm --filter @watcher/osint-bot typecheck
pnpm exec vitest run apps/osint-bot/src/__tests__
```

Manual investigations run immediately. Persisted watches are polled on the
configured interval, default five minutes, without overlapping the same work.

## Integrations

Collectors include ARES, Registr smluv, RÚIAN, ČÚZK INSPIRE, website metadata,
DNS, RDAP, Certificate Transparency, Wayback, Wikipedia, GitHub, Reddit, ORCID,
Crossref, selected public social metadata, and public Bitcoin/Ethereum summaries.

## Troubleshooting

- CAPTCHA or blocked cadastral pages are terminal source limitations; the bot
  does not bypass them or scrape Nahlížení do KN.
- Multiple name candidates are not an identity error—add stronger selectors.
- Review `/sources`, evidence provenance, and collector errors before enabling
  more concurrency.
- Phone-number reverse lookup is intentionally unsupported.
