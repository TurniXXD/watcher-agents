## Overview

Transport Bot normalizes a configured request feed, rejects loads that cannot be
proven to fit, routes viable candidates, and ranks only opportunities satisfying
persisted profit, profit/hour, empty-distance, detour, and confidence thresholds.
It never bids, accepts jobs, or contacts customers.

## Commands and keyboard actions

| Command/action           | What it does                                                                          |
| ------------------------ | ------------------------------------------------------------------------------------- |
| `/start`                 | Initializes the bot and begins vehicle setup when needed.                             |
| `/help`                  | Shows the complete guide without changing setup progress.                             |
| `/about`                 | Explains the decision model, sources, and safety boundaries.                          |
| `🚐 Vehicle`             | Adds or replaces dimensions, capacity, consumption, and restrictions.                 |
| `📊 Cost settings`       | Configures wear, maintenance, tyres, oil, insurance, labour, and optional fuel price. |
| `⚙️ Preferences`         | Configures profit, distance, detour, and confidence gates.                            |
| `🔎 Find jobs`           | Evaluates the current request feed immediately.                                       |
| `🛣️ I'm planning a trip` | Finds compatible incremental loads for a route.                                       |
| `🔄 Find return load`    | Reverses the last planned trip and evaluates return loads.                            |

## Architecture and flow

Manual search and proactive discovery share one evaluator. Cargo dimensions and
weight must be known before compatibility passes. Planned-trip recommendations
charge incremental distance and time. Routing uses an OSRM-compatible service;
fuel cost can use the European Commission bulletin converted with the CNB daily
rate.

## Configuration

| Variable                               | Required/default              | Purpose                                                                      |
| -------------------------------------- | ----------------------------- | ---------------------------------------------------------------------------- |
| `DATABASE_URL`                         | Required                      | PostgreSQL vehicle, preferences, and delivery state.                         |
| `TRANSPORT_TELEGRAM_TOKEN`             | Required                      | Dedicated Telegram token.                                                    |
| `TELEGRAM_ALLOWED_USER_IDS`            | Required                      | Authorized private operators.                                                |
| `TRANSPORT_REQUEST_FEED_URL`           | Required                      | Operator-owned load-request JSON feed.                                       |
| `TRANSPORT_REQUEST_FEED_TOKEN`         | Optional                      | Bearer token for the request feed.                                           |
| `TRANSPORT_OSRM_URL`                   | Configured default            | OSRM-compatible routing endpoint; production should not use the public demo. |
| `TRANSPORT_FUEL_BULLETIN_URL`          | Optional/default provider URL | European Commission fuel bulletin.                                           |
| `TRANSPORT_CNB_RATE_URL`               | Optional/default provider URL | CNB daily exchange-rate feed.                                                |
| `TRANSPORT_DISCOVERY_INTERVAL_MINUTES` | `15`                          | Proactive discovery interval.                                                |
| `TRANSPORT_HEALTH_PORT`                | Configured default            | Private readiness port.                                                      |
| `LOG_LEVEL`                            | `info`                        | Structured log level.                                                        |

## Execution and scheduling

```bash
pnpm --filter @watcher/transport-bot dev
pnpm --filter @watcher/transport-bot typecheck
pnpm exec vitest run apps/transport-bot/src/__tests__
```

Proactive discovery defaults to every 15 minutes. The feed accepts an array or
`{ "requests": [...] }`; absent values must be omitted rather than represented as
made-up zeroes.

## Integrations

The request feed is operator-owned, routing is OSRM-compatible, fuel pricing can
come from the European Commission bulletin, and currency conversion can use CNB.
Telegram and PostgreSQL provide control and persisted thresholds.

## Troubleshooting

- Unknown cargo dimensions/weight intentionally produce incompatibility rather
  than optimistic ranking.
- The public OSRM project service is development-only; use a production-grade
  endpoint for reliable operation.
- Missing fuel/rate data lowers confidence and should not be silently replaced.
- Validate the normalized request shape when the feed returns zero candidates.
