## Overview

Sales Bot discovers Czech businesses through ARES and Geoapify, optionally uses
Google Places fallback, crawls public company websites, stores evidence, scores
leads, prepares grounded drafts, and integrates with Quickly and Twenty when
configured. Personal contacts and business-card reading are also available in
the separate Networking Bot. Sales keeps the same commands for backward
compatibility; event discovery and event follow-ups belong only to Networking.

Use `/start`, `/help`, or `/sales_help` for the current guide. Sales commands
include `/sales_status`, `/sales_campaigns`, `/sales_prospects`,
`/sales_search`, `/sales_searches`, `/sales_search_stop`, `/sales_find`,
`/sales_calls`, `/sales_leads`, `/sales_lead`, `/sales_approve`,
`/sales_reject`, and `/sales_run`.

The backward-compatible contact commands continue to use the `/network_`
prefix and the same preview-and-confirm business-card workflow as Networking
Bot.

## Architecture and flow

Discovery maps a Czech or English business description to validated Geoapify and
CZ-NACE categories, queries providers, enriches public sites, records evidence,
and scores leads. Periodic search stores its cursor and emits only new contacts.
Lead research and call lists do not send email.

`/sales_prospects <business type> | <location> | [limit]` performs a separate
campaign-free CRM import. It defaults to 10 results, accepts 1–20, audits public
websites for an email and explicit `tel:` link, and upserts a Twenty Company plus
a linked Note containing the contact values and source URLs. PostgreSQL records
provider identity, domain, IČO, contact evidence, and Twenty IDs so subsequent
runs skip a completed prospect. The command does not create a campaign, draft,
approval, or Quickly enrollment.

Quickly enrollment fails closed unless a qualified approved lead has explicit
`RECIPIENT_OPT_IN` or `EXISTING_CUSTOMER` evidence, no suppression, an enabled
campaign, and available capacity. Public contact data or Telegram approval alone
is not consent.

## Execution and scheduling

```bash
pnpm --filter @watcher/sales-bot dev
pnpm --filter @watcher/sales-bot typecheck
pnpm exec vitest run apps/sales-bot/src/__tests__
```

Periodic work defaults to 30-minute intervals; follow-up reporting defaults to
20:00 in `Europe/Prague`. Manual and scheduled discovery use the same persisted
search and lead pipeline. The campaign-free prospect import is one-shot and must
be invoked explicitly.

## Integrations

| Source/service                       | Role                                                                            |
| ------------------------------------ | ------------------------------------------------------------------------------- |
| ARES                                 | Official Czech company identity, registered address, IČO, and CZ-NACE evidence. |
| Geoapify/OpenStreetMap               | Primary place discovery and available public contact metadata.                  |
| Google Places                        | Optional fallback when primary sources lack enough contacts.                    |
| Public company websites              | Contact-page, explicit e-mail, and `tel:` evidence with source URLs.            |
| Twenty CRM                           | Idempotent Company/Note CRM state; extended by Twenty Sales App when enabled.   |
| Quickly                              | Explicitly authorized campaign sequences after every eligibility gate passes.   |
| Ollama                               | Optional category mapping and schema-validated draft generation.                |
| Google Sheets/contact-network        | Backward-compatible personal-contact workflow shared with Networking Bot.       |
| Telegram, Sales REST API, PostgreSQL | Private control surfaces and authoritative workflow state.                      |

## Troubleshooting

- An empty call list means no analyzed lead currently has a public phone; run
  search/discovery and analysis, then inspect evidence.
- `/sales_prospects` imports only candidates with a website. A result without an
  official website is counted as found but is not written to Twenty.
- Category mapping prints the Geoapify/CZ-NACE categories actually used. Supply
  `geo:` or `nace:` for an explicit override.
- Quickly refusal is expected when consent, suppression, campaign, or capacity
  requirements are not satisfied.
