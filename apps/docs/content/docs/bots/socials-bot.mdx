## Overview

Socials Bot is a private Czech Telegram workflow for personal-brand planning and
trend intelligence. PostgreSQL is authoritative, Notion is an optional
editorial mirror, and ChatGPT remains a manual high-quality writing step. The bot
does not publish to social networks, a website, or a newsletter.

Use `/start` or `/socials` for the main menu, `/about` for the purpose, data
model, automation, and publishing boundaries, and `/help` or `/socials_help` for
the complete command guide.

## Architecture and flow

<Mermaid
  label="Socials Bot evidence, planning, approval, and feedback workflow"

    K --> E`}

`SocialsStore` owns relational persistence and versions; `SocialsService` owns
capture, planning, packs, analytics, and optional Notion sync;
`SocialsScheduler` owns durable reminders; lightweight Qwen classification has a
deterministic fallback.

Trend Intelligence gathers bounded YouTube and approved Reddit evidence plus
credential-free Bluesky, Hacker News, public Mastodon trends, and configured
RSS/Atom feeds. It accepts authorized manual imports, clusters repeated
observations, compares US and Czech signals, keeps opportunity score separate
from evidence confidence, and produces schema-validated Czech concepts.
Feedback applies only a small transparent future-ranking correction.

## Integrations

- Notion mirrors the content calendar with two-sided conflict detection.
- YouTube Data API v3, approved Reddit OAuth, public Bluesky AppView, Hacker
  News Firebase, Mastodon trend endpoints, and RSS/Atom are automated trend
  sources.
- Google Trends, TikTok, and broad Instagram discovery are manual-only without an
  authorized supported API.
- An OpenAI-compatible endpoint can transcribe voice input.

## Troubleshooting

- Notion `object_not_found` means the data source/page was not shared with the
  integration or the wrong data-source ID was configured.
- First-day trend momentum is normally unknown because growth needs repeated
  observations.
- A source marked `ERROR` now includes a bounded diagnostic below the report.
  For YouTube, check API enablement, key restrictions, and daily quota; the
  report distinguishes common Google API reasons such as `quotaExceeded`.
- To keep research running without YouTube credentials, use
  `/socials_trends run BLUESKY,HACKERNEWS,MASTODON`. A same-day run with the
  same source set is intentionally cached; changing the set creates a distinct
  idempotency key.
- Mastodon instances may disable or protect trend endpoints; configure multiple
  instances so one server does not represent the entire Fediverse.
- RSS URLs and every redirect must resolve only to public HTTP(S) addresses.
- Missing source credentials appear as unavailable and do not block other
  sources.
- A conflict status protects simultaneous local and Notion edits; resolve it
  manually instead of overwriting one side.
